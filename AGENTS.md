# Инструкции для ИИ-агентов (любой модели)

Этот файл — точка входа для агентов и моделей, которые не читают `CLAUDE.md` автоматически: Codex CLI, Cursor, Gemini CLI, Aider, OpenCode и другие, а также ChatGPT, DeepSeek, GLM и прочие модели в чате. Если ваш инструмент не подхватил этот файл сам, начните диалог словами «Прочитай AGENTS.md и следуй ему».

Файлы `CLAUDE.md` названы по имени модели, с которой репозиторий ведётся, но **все правила в них относятся к любой модели**. Источник истины — они; этот файл только помогает начать.

## Что это за репозиторий

Личный репозиторий студента Leo для изучения математики по программе вплоть до уровня современных исследований. Все файлы и общение — на русском языке. Структура описана в [`CLAUDE.md`](CLAUDE.md) в корне.

- `Reality Check/` — программа (`PLAN.md`) и 79 экзаменов по дисциплинам программы (`Exams/`), варианты для пересдач (`Variants/`), попытки студентов и отчёты о проверке (`Students/<Имя>/`), скрипты (`tools/`).
- `Drafts/` и `Study Materials/` — личные материалы владельца, к экзаменам отношения не имеют.

## Перед любой работой с экзаменами

1. Выполнить `git pull`.
2. Прочитать целиком [`Reality Check/CLAUDE.md`](Reality%20Check/CLAUDE.md) — формат экзамена, выдача, варианты, проверка, правила формул — и [`Reality Check/GRADING.md`](Reality%20Check/GRADING.md) — протокол проверки. Попытки и выдача описаны в [`Reality Check/Students/README.md`](Reality%20Check/Students/README.md).

## Главные правила (подробности — в файлах выше)

- **Ключ не показывать.** Файл экзамена содержит ключ в конце. Студент решает по `exam.pdf` или по условиям до строки «## Карта навыков»; содержимое ключа, критериев, «Карты навыков» и «Диагностики по профилю» до проверки не пересказывать.
- **Проверка — строго по `GRADING.md`**: сначала самостоятельно решить и оценить по существу, затем сверить с ключом; отчёт `REPORT.md` — в папку попытки, по шаблону из `GRADING.md`, с названием модели в строке «Проверено».
- **Галочки в `PLAN.md` ставятся только Leo** (итог ≥ 75). Попытки других студентов лежат в `Students/<Имя>/`, им пишется отчёт и строка журнала в `Reality Check/README.md`, но не галочка.
- **Формулы в markdown** — только синтаксис из раздела «Формулы» `Reality Check/CLAUDE.md` (`` $`...`$ ``, блоки `math`, без `\operatorname`, пробел после `<` перед буквой).
- **Экзамены и варианты не переписывать без нужды.** Составление новых экзаменов и вариантов требует проверки вычислений (`sympy`), гейта `python3 -I "Reality Check/tools/verify_exam.py" <файл>` и независимой рецензии; без них результат помечается как непроверенный.
- **Коммиты и пуш** — только в своём клоне или форке. В репозиторий Leo изменения попадают через Leo или pull request.

## Если вы студент и работаете в своём клоне

Короткая инструкция — в разделе «Сдача с другой моделью или без доступа к репозиторию» файла [`Reality Check/Students/README.md`](Reality%20Check/Students/README.md): как получить условия без ключа, какой промпт дать модели для проверки и как передать результат Leo.
