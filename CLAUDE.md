# Leo — заметки для Claude

Личный репозиторий владельца (студент Leo) для изучения математики по плану вплоть до уровня современных исследований. Общение и все файлы — на русском языке.

## Структура

- `AGENTS.md` — точка входа для других моделей и инструментов (Codex CLI, Cursor, Gemini CLI, ChatGPT, DeepSeek, GLM …): те же правила, ссылки на нужные файлы.
- `Reality Check/` — программа и экзамены: `PLAN.md` (атлас дисциплин и трекер прогресса), `Exams/` (79 экзаменов, по одному на дисциплину), `Variants/` (варианты для пересдач), `Students/<Имя>/` (попытки и отчёты о проверке), `tools/exam_pdf.py`, архив PDF условий, `program_atlas.pdf` — описание программы (атлас без банков КТ), `vertices_guide.pdf` — путеводитель по вершинам V1–V6. **Все инструкции по работе с программой и экзаменами — в [`Reality Check/CLAUDE.md`](Reality%20Check/CLAUDE.md)**: формат экзамена, выдача, варианты, проверка, правила оформления формул. Читать его перед любой задачей, связанной с экзаменами или планом.
- `Study Materials/` — учебные материалы (пока пусто; файл `.gitkeep` нужен только для того, чтобы git хранил пустую папку).
- `Drafts/` — черновики и рабочие материалы владельца, не связанные с экзаменами:
  - `Drafts/Galois Theory/` — письменные разборы по теории Галуа (PDF) и учебник, по которому они написаны:
    `Milne_Fields_and_Galois_Theory_v5.10.pdf` — J. S. Milne, «Fields and Galois Theory», v5.10 (сентябрь 2022, 144 с., лицензия CC BY-NC-SA 4.0). Разборы ссылаются на его нумерацию (гл. 1–9, утверждения вида 7.16). Там же `Leo_handwritten_notes_Galois_Theory.pdf` — рукописный конспект владельца по Милну (гл. 1–7, 269 с., скан): исходный материал для будущего русского конспекта по теории Галуа. Второй источник для гл. 1–5 — старый рукописный конспект владельца (текст плотнее, вопросы помечены «? [N.k]» — вопрос k к главе N, перечёркнутый = отвеченный): `Leo_old_notes_Galois_Theory_title_page.jpg` (первая страница: счётчики вопросов и задач по главам, список тем для подробного разбора, нерешённые задачи) и `Leo_old_notes_Galois_Theory_Chapter_5.pdf` (гл. 5, 24 с.; остальные главы будут добавлены).
    `Konspekt/` — сам русский конспект по теории Галуа (по главам Милна, нумерация утверждений — Милна; дополнительные утверждения — с буквами, например 7.8a). `Konspekt_Teoriya_Galua.pdf` — **общий файл** (титул, предисловие, оглавление, все готовые главы; ссылки между главами кликабельны), `Glava_<N>_….pdf` — отдельные главы. Исходники LaTeX — в `src/` (pdflatex, T2A): `preamble.tex` — общая преамбула; `preface.tex` — предисловие; `Konspekt.tex` — общий файл (глава N подключается строками `\setcounter{chapter}{N-1}\subimport{chN/}{body}`); `src/ch<N>/` — `body.tex` (заголовок главы и разделы `s*.tex`) и `ch<N>.tex` (отдельный PDF главы); `src/tools/convert_refs.py` превращает номера-ссылки в тексте в `\rf{…}`, `src/tools/check_refs.py` после сборки общего файла ищет ссылки на несуществующие номера готовых глав. Утверждения нумеруются вручную номерами Милна (`\begin{proposition}[7.2]`, `[7.13: основная теорема]`), метка `st:<номер>` ставится автоматически; ссылка — `\rf{7.2}`: переход, если утверждение есть в файле, иначе просто номер. При добавлении главы N сверять по содержанию все ссылки старших глав на неё. Основной текст — самостоятельный учебный текст: без упоминаний источников, автора рукописи и поправок к Милну; об источниках и о том, как сделан конспект, говорит только предисловие (по просьбе владельца 2026-11-13). Иллюстрации, замечания и комментарии из рукописи владельца сохраняются (перерисовываются в TikZ/tikz-cd; цветом выделяются стрелки и объекты, которые строятся в доказательстве); в трудных местах можно добавлять новые рисунки. Готово: гл. 6, 7. Главы 1–7 владельцем прочитаны полностью (включая гл. 7 «Infinite Galois Extensions»), кроме упражнений 4-8–4-10, 5-1–5-4 и 7-1–7-3 (нумерация упражнений Милна). В тексте о владельце (предисловие и т. п.) не использовать формы с грамматическим родом: «по заданию и под руководством составителя», «решает составитель»;
  - `Drafts/K-Stability and K-Moduli/` — конспекты по K-стабильности (LaTeX), независимы от программы; правила — в README этой папки.

Файлы `trajectory.txt` (исходный список дисциплин, из которого вырос план) и `exam-ideas.txt` (замечания владельца к формату экзаменов от 2026-10-23, реализованные в `Reality Check/`) удалены 2026-10-30; их содержимое есть в истории git.

## Перед любой работой

Выполнить `git pull`: владелец загружает файлы через веб-интерфейс GitHub.

## Соглашения

- Типографика: «ёлочки», длинное тире —, буква ё.
- **Математическая терминология на русском** — только устоявшиеся русские термины, а не кальки с английского. Сомневаешься — проверь по русской литературе (Винберг, Кострикин, Ленг в переводе, Атья–Макдональд в переводе) и не выдумывай. Примеры: profinite group — **проконечная** группа (не «профинитная»); perfect pairing — совершенное спаривание; splitting field — поле разложения; purely inseparable — чисто несепарабельное; separable closure — сепарабельное замыкание; normal closure — нормальное замыкание; Krull topology — топология Крулля; inverse (projective) limit — обратный (проективный) предел; directed set — направленное множество; totally disconnected — вполне несвязное; neighbourhood base — база (фундаментальная система) окрестностей; crossed homomorphism — скрещённый гомоморфизм; étale algebra — этальная алгебра; cyclotomic field / polynomial — круговое поле / круговой многочлен; primitive element — примитивный элемент; transcendence basis — базис трансцендентности; Frobenius element — элемент Фробениуса.
- Формулы в markdown — только по разделу «Формулы» в `Reality Check/CLAUDE.md` (GitHub-совместимый синтаксис `` $`...`$ `` и блоки `math`).
- Коммиты делаются прямо в `main`. Пушить на GitHub, если владелец просил или подтвердил.
