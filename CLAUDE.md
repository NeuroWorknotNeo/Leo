# Leo — заметки для Claude

Личный репозиторий для изучения математики по плану вплоть до уровня современных исследований. Общение и все файлы — на русском языке.

## Структура

- `plan.md` — атлас дисциплин и трекер прогресса. Чекбоксы стоят в Части I, карточки дисциплин с якорями `#a1`, `#g9` и т. п. — в Части III.
- `Galois Theory/` — письменные разборы владельца (PDF).
- `Reality Check/` — двухчасовые диагностики по каждой дисциплине плана (71 экзамен, части A–E, 100 баллов):
  - `README.md` — правила, шкала уровней, журнал попыток, оглавление;
  - `GRADING.md` — протокол проверки;
  - `Attempts/<Код>/<дата>/` — решения и отчёты о проверке.

## Перед любой работой

Выполнить `git pull`: владелец загружает файлы через веб-интерфейс GitHub.

## Проверка экзаменов

Когда просят проверить или оценить попытку экзамена, следовать `Reality Check/GRADING.md` полностью: строгая оценка, отчёт `REPORT.md`, запись в журнал, галочка в `plan.md` при выполнении критерия.

## Соглашения

- Типографика: «ёлочки», длинное тире —, буква ё.
- Формулы: GitHub-math (`$...$`, `$$...$$` с пустыми строками вокруг). Внутри формул после `<` ставить пробел, иначе GitHub может принять его за HTML-тег. Не писать формулы с `|` в ячейках таблиц.
- Внутри `<details>` после `<summary>` обязательно пустая строка.
- Новые диагностики или варианты — по шаблону существующих файлов в `Reality Check/`.
- Коммиты делаются прямо в `main`. Пушить на GitHub, если владелец просил или подтвердил.
