# Leo — заметки для Claude

Личный репозиторий владельца (студент Leo) для изучения математики по плану вплоть до уровня современных исследований. Общение и все файлы — на русском языке.

## Структура

- `AGENTS.md` — точка входа для других моделей и инструментов (Codex CLI, Cursor, Gemini CLI, ChatGPT, DeepSeek, GLM …): те же правила, ссылки на нужные файлы.
- `Reality Check/` — программа и экзамены: `PLAN.md` (атлас дисциплин и трекер прогресса), `Exams/` (79 экзаменов, по одному на дисциплину), `Variants/` (варианты для пересдач), `Students/<Имя>/` (попытки и отчёты о проверке), `tools/exam_pdf.py`, архив PDF условий, `program_atlas.pdf` — описание программы (атлас без банков КТ), `vertices_guide.pdf` — путеводитель по вершинам V1–V6. **Все инструкции по работе с программой и экзаменами — в [`Reality Check/CLAUDE.md`](Reality%20Check/CLAUDE.md)**: формат экзамена, выдача, варианты, проверка, правила оформления формул. Читать его перед любой задачей, связанной с экзаменами или планом.
- `Study Materials/` — учебные материалы (пока пусто; файл `.gitkeep` нужен только для того, чтобы git хранил пустую папку).
- `Drafts/` — черновики и рабочие материалы владельца, не связанные с экзаменами:
  - `Drafts/Galois Theory/` — письменные разборы по теории Галуа (PDF);
  - `Drafts/K-Stability and K-Moduli/` — конспекты по K-стабильности (LaTeX), независимы от программы; правила — в README этой папки.

Файлы `trajectory.txt` (исходный список дисциплин, из которого вырос план) и `exam-ideas.txt` (замечания владельца к формату экзаменов от 2026-10-23, реализованные в `Reality Check/`) удалены 2026-10-30; их содержимое есть в истории git.

## Перед любой работой

Выполнить `git pull`: владелец загружает файлы через веб-интерфейс GitHub.

## Соглашения

- Типографика: «ёлочки», длинное тире —, буква ё.
- Формулы в markdown — только по разделу «Формулы» в `Reality Check/CLAUDE.md` (GitHub-совместимый синтаксис `` $`...`$ `` и блоки `math`).
- Коммиты делаются прямо в `main`. Пушить на GitHub, если владелец просил или подтвердил.
