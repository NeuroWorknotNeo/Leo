# Попытки студентов и отчёты о проверке

Здесь хранятся попытки сдать экзамен, по одной папке на попытку. У каждого студента своя папка; `Leo` — владелец программы, остальные — другие люди, которые сдают те же экзамены.

```
Students/<Имя>/<Код>/<дата выдачи>/
    exam.pdf     — условия, которые решались (кладёт Claude при выдаче)
    notes.md     — вариант и коммит экзамена (заполняет Claude) + условия сдачи (дописывает студент)
    01.jpg, …    — решения (загружает студент)
    REPORT.md    — отчёт о проверке (создаёт Claude)
```

Например: `Students/Leo/A2/2026-11-01/`. Дата в имени папки — день, когда экзамен выдан; когда он фактически сдавался, пишется в `notes.md`. Общая схема «выдача → сдача → проверка → пересдача» — в [README.md](../README.md#как-сдавать).

## Как получить экзамен

Leo пишет Claude: «Хочу сдать A2» (или «Сделай вариант для пересдачи A2»). Для другого студента: «Выдай A2 студенту Ivan» (или «Сделай вариант A2 для пересдачи студента Ivan»). Claude создаст папку попытки с `exam.pdf` и заготовкой `notes.md` и отправит её на GitHub. Решать по `exam.pdf`; файл экзамена в репозитории не открывать: в нём ключ.

Если папка создаётся вручную, без Claude: условия собираются командой `python3 "Reality Check/tools/exam_pdf.py" <экзамен.md> -o "Reality Check/Students/<Имя>/<Код>/<дата>/exam.pdf"` (для варианта добавить `--variant vN`), а в `notes.md` нужно записать вариант (`v1` — основной экзамен) и коммит, который скрипт печатает при сборке.

Образец `notes.md`:

```
# A2. Общая алгебра — попытка

- **Студент:** Leo
- **Вариант:** v1 — [`Exams/Algebra/A2_Abstract_Algebra.md`](../../../../Exams/Algebra/A2_Abstract_Algebra.md), коммит `abc1234`
- **Выдан:** 2026-11-01, условия — [`exam.pdf`](exam.pdf)
- **Сдача:** <дата; сколько минут ушло>
- **Материалы:** <не использовались / что именно>
- **Комментарий:** <что не успел, что дописано после звонка таймера>
```

## Что положить в папку попытки после сдачи

- **Решения**, в любом из форматов:
  - фото или сканы листов: `01.jpg`, `02.jpg`, … в порядке страниц;
  - один `solutions.pdf`;
  - текст `solutions.md` (можно с формулами `$...$`).
- **Дописать в `notes.md`** строки «Сдача», «Материалы», «Комментарий», например:

  ```
  Сдача: 2026-11-05, один заход, 175 минут
  Материалы: не использовались
  Комментарий: E2 не успел, D1 (в) дописывал после звонка таймера
  ```

## Как загрузить через GitHub

1. Открыть на github.com папку попытки, например `Reality Check/Students/Leo/A2/2026-11-01`.
2. Нажать «Add file» → «Upload files», перетащить фото или PDF и нажать «Commit changes».
3. Открыть `notes.md`, нажать значок карандаша, дописать условия сдачи и снова «Commit changes».

## Как попросить проверку

В новом диалоге с Claude, открытом в папке репозитория, достаточно написать:

> Проверь мою попытку A2 от 2026-11-01.

или для другого студента:

> Проверь попытку A2 студента Ivan от 2026-11-01: сдавал 2026-11-05, один заход, 175 минут, без материалов.

Claude проверит её по [протоколу](../GRADING.md), положит `REPORT.md` в ту же папку и запишет результат в журнал попыток в [README.md](../README.md#журнал-попыток). Галочка в [PLAN.md](../PLAN.md) ставится только по попыткам Leo.

Если решения не загружены в репозиторий, можно прислать фото или текст прямо в диалог. Отчёт всё равно сохранится здесь.

## Правила честной попытки

- 180 минут, один заход, бумага и ручка; никаких книг, конспектов, интернета и CAS.
- Ключ не открывать до проверки. Файл экзамена в репозитории содержит ключ, поэтому решать только по `exam.pdf`.
- Решения не переписывать начисто «с улучшениями». Достаточно разборчиво переписать то, что было написано за время экзамена, и отдельно пометить, что дописано позже.

## Другие студенты

- Условия сдачи и протокол проверки для всех одинаковые; отличие одно — галочки в PLAN.md ставятся только Leo.
- Если Leo ещё не сдавал вариант, который сдаёт другой студент, Claude в диалоге сообщает только баллы и уровень, без решений, а Leo лучше не открывать `REPORT.md` и решения студента до собственной сдачи.
- Вариант для пересдачи другого студента составляется по его отчётам, вариант для Leo — по отчётам Leo. Замечания о трудности и ошибках в ключе из любых попыток учитываются при правке экзаменов.
