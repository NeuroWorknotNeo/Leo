# Варианты экзаменов

Основной экзамен каждой дисциплины — вариант **v1** — лежит в `Exams/<Область>/<Код>_<Название>.md`. Здесь хранятся следующие варианты, которые Claude составляет для пересдач и для других студентов:

```
Variants/<Код>/v2.md
Variants/<Код>/v3.md
…
```

Номера сквозные по коду экзамена, независимо от того, для кого составлен вариант. **Файлы с ключом открывать нельзя:** они устроены как основной экзамен, ключ в конце свёрнут. Условия для решения берутся из `exam.pdf` в папке попытки.

## Правила составления варианта

1. **Формат тот же, что у основного экзамена:** 180 минут, части A–E с теми же баллами и временем (10 / 15 / 30 / 30 / 15), та же шапка, карта навыков, интерпретация, правило галочки и ключ с критериями. Спецификация формата — в [CLAUDE.md](../CLAUDE.md). Иначе результат пересдачи нельзя сравнить с прошлыми.
2. **Покрытие.** Как и в v1, задачи распределяются по темам «Содержания» равномерно, а самые важные темы дисциплины присутствуют обязательно. При этом в приоритете моменты дисциплины, которые не вошли в предыдущие варианты; где удачно заменить задачу не получается, берётся похожая задача с изменёнными условиями.
3. **Учёт отчётов.** Больше веса получают темы, по которым студент в прошлых попытках (его `REPORT.md`) потерял больше половины баллов, меньше — задачи, с которыми он справился. Если до решения не хватило какого-то рассуждения, оно добавляется как пункт части A или B. Задачи из прошлых попыток не повторяются. Для Leo используются отчёты Leo, для другого студента — его отчёты.
4. **Часть D** берётся из банка контрольных точек карточки в [PLAN.md](../PLAN.md#part3): в первую очередь доказательства, которые студент не осилил, затем ещё не спрашивавшиеся; хотя бы одно из трёх — центральная теорема дисциплины.
5. **Шапка варианта:** заголовок `# <Код>. <Название> — диагностика, вариант vN` и под цитатой-шапкой строка «**Составлен:** <дата> для <студент> по попыткам <даты>; усилены темы: …».
6. **Качество.** Вариант составляет сильная модель: каждое вычисление проверяется (`sympy`), затем независимый рецензент заново решает задачи и сверяет ключ. Оформление формул — по разделу «Формулы» в [CLAUDE.md](../CLAUDE.md), проверка — через API GitHub.
7. **После выдачи вариант меняют только ради исправления ошибок** — отдельным коммитом, с пометкой в отчёте о проверке. Новые задачи — это уже следующий вариант. `notes.md` попытки хранит коммит, по которому был собран `exam.pdf`, поэтому всегда видно, какую версию решал студент.
8. **Невыданный вариант.** Вариант считается выданным, если на него ссылается `notes.md` какой-нибудь попытки. Если по коду лежит невыданный вариант, составленный для того же студента, выдаётся он, а не новый.

## Особенности отдельных экзаменов

- **A4.** Вариант [v2](A4/v2.md) составлен 2026-10-23 до перехода на новый формат: 180 минут, части 10 / 10 / 30 / 30 / 20 баллов, D1 и D2 по 5 баллов. Он выдан Leo (`Students/Leo/A4/2026-10-23`) и проверяется по собственной разбалловке; итог из 100 и уровень сравнимы с остальными. Следующие варианты A4 — в новом формате.

Как выдаётся экзамен и где лежат попытки — в [README.md](../README.md#как-сдавать).
