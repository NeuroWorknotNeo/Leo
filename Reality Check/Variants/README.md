# Варианты экзаменов для пересдач

Основной экзамен каждой дисциплины — вариант **v1** — лежит в папке своей области, например `Algebra/A2_Abstract_Algebra.md`. Здесь хранятся следующие варианты, которые Claude составляет для пересдач по результатам прошлых попыток:

```
Variants/<Код>/v2.md
Variants/<Код>/v3.md
…
```

**Файлы с ключом открывать нельзя:** они устроены как основной экзамен, ключ в конце свёрнут. Условия для решения берутся из `exam.pdf` в папке попытки.

## Правила составления варианта

1. **Структура та же, что у основного экзамена:** части A–E, те же баллы, то же время, та же шапка, карта навыков, интерпретация, правило галочки и ключ с критериями. Иначе результат пересдачи нельзя сравнить с прошлыми.
2. **Контрольная точка та же:** задача D с пометкой «контрольная точка» проверяет ту же теорему из `plan.md`, но в другой формулировке или с другим путём доказательства.
3. **Задачи новые.** Больше веса получают темы из «Карты навыков», по которым в прошлых отчётах (`Attempts/<Код>/*/REPORT.md`) потеряно больше половины баллов. Задачи из прошлых попыток не повторять.
4. **Шапка варианта:** заголовок `# <Код>. <Название> — диагностика, вариант vN` и под цитатой-шапкой строка «**Составлен:** <дата> по попыткам <даты>; усилены темы: …».
5. **Качество.** Вариант составляет сильная модель (Opus): каждое вычисление проверяется (`sympy`), затем независимый рецензент заново решает задачи и сверяет ключ. Оформление формул — по разделу «Формулы» в [CLAUDE.md](../../CLAUDE.md), проверка — через API GitHub.
6. **После выдачи вариант меняют только ради исправления ошибок** — отдельным коммитом, с пометкой в отчёте о проверке. Новые задачи — это уже следующий вариант. `notes.md` попытки хранит коммит, по которому был собран `exam.pdf`, поэтому всегда видно, какую версию решал студент.

Как выдаётся экзамен и где лежат попытки — в [README.md](../README.md#variants).
