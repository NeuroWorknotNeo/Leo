# Попытки и отчёты о проверке

Здесь хранятся попытки сдать экзамен, по одной папке на попытку:

```
Attempts/<Код>/<дата выдачи>/
    exam.pdf     — условия, которые решались (кладёт Claude при выдаче)
    notes.md     — вариант и коммит экзамена (заполняет Claude) + условия сдачи (дописывает студент)
    01.jpg, …    — решения (загружает студент)
    REPORT.md    — отчёт о проверке (создаёт Claude)
```

Например: `Attempts/A2/2026-10-21/`. Дата в имени папки — день, когда экзамен выдан; когда он фактически сдавался, пишется в `notes.md`. Общая схема «выдача → сдача → проверка → пересдача» — в [README](../README.md#variants).

## Как получить экзамен

Написать Claude: «Хочу сдать A2» (или «Сделай вариант для пересдачи A2»). Claude создаст папку попытки с `exam.pdf` и заготовкой `notes.md` и отправит её на GitHub. Решать по `exam.pdf`; файл экзамена в репозитории не открывать: в нём ключ.

Если папка создаётся вручную, без Claude: условия собираются командой `python3 "Reality Check/tools/exam_pdf.py" <экзамен.md> -o "Reality Check/Attempts/<Код>/<дата>/exam.pdf"`, а в `notes.md` нужно записать вариант (`v1` — основной экзамен) и коммит, который скрипт печатает при сборке.

## Что положить в папку попытки после сдачи

- **Решения**, в любом из форматов:
  - фото или сканы листов: `01.jpg`, `02.jpg`, … в порядке страниц;
  - один `solutions.pdf`;
  - текст `solutions.md` (можно с формулами `$...$`).
- **Дописать в `notes.md`** строки «Сдача», «Материалы», «Комментарий», например:

  ```
  Сдача: 2026-10-25, один заход, 120 минут
         (или: два захода; для расширенного экзамена по физике: 110 + 80 минут, A–C и D–E)
  Материалы: не использовались
  Комментарий: E2 не успел, D1(в) дописывал после звонка таймера
  ```

## Как загрузить через GitHub

1. Открыть на github.com папку попытки, например `Reality Check/Attempts/A2/2026-10-21`.
2. Нажать «Add file» → «Upload files», перетащить фото или PDF и нажать «Commit changes».
3. Открыть `notes.md`, нажать значок карандаша, дописать условия сдачи и снова «Commit changes».

## Как попросить проверку

В новом диалоге с Claude, открытом в папке репозитория, достаточно написать:

> Проверь мою попытку A4 от 2026-10-21.

Claude проверит её по [протоколу](../GRADING.md), положит `REPORT.md` в ту же папку, обновит журнал попыток в [README](../README.md) и при выполнении критерия поставит галочку в `plan.md`.

Если решения не загружены в репозиторий, можно прислать фото или текст прямо в диалог. Отчёт всё равно сохранится здесь.

## Правила честной попытки

- Ключ не открывать до проверки.
- Решения не переписывать начисто «с улучшениями». Достаточно разборчиво переписать то, что было написано за время экзамена (120 минут или время из шапки расширенного экзамена по физике), и отдельно пометить, что дописано позже.
