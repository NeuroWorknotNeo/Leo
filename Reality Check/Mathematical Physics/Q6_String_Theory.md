Намбу–Гото: $`X\colon\mathbb{R}\times S^1\to\mathbb{R}^{1,D-1}`$ — погружение, индуцированная метрика $`\gamma_{ab}=\partial_aX\cdot\partial_bX`$ лоренцева ($`\det\gamma<0`$, мировой лист времениподобен); $`S_{NG}=-\frac1{2\pi\alpha'}\int d^2\sigma\sqrt{-\det\gamma}`$ — натяжение, умноженное на площадь. Диффеоморфизмы и Вейль позволяют локально положить $`h=\eta`$. Критерии: действия и условия — 1; симметрии и эквивалентность — 1.

Центральное расширение: $`0\to\mathbb{C}C\to\hat{\mathfrak{g}}\to\mathfrak{g}\to0`$ с центральным $`C`$; для линейного сечения $`s`$ имеем $`[s(x),s(y)]=s([x,y])+\omega(x,y)C`$, где $`\omega`$ — 2-коцикл (кососимметричность и тождество Якоби); замена сечения $`s\mapsto s+fC`$ меняет $`\omega`$ на кограницу $`f([x,y])`$; классы эквивалентных расширений — $`H^2(\mathfrak{g};\mathbb{C})`$, расщеплённое расширение — нулевой класс. В конформной калибровке в координатах $`\sigma^\pm`$: $`T_{+-}=0`$, и сохранение даёт $`\partial_-T_{++}=0`$, $`\partial_+T_{--}=0`$. Связи: $`T_{++}\propto\partial_+X\cdot\partial_+X=0`$, $`T_{--}\propto\partial_-X\cdot\partial_-X=0`$ (это уравнение по $`h`$, оставшееся после фиксации калибровки); в модах — $`L_n=\tilde L_n=0`$ при всех $`n`$ (квантово: $`L_n\lvert\psi\rangle=0`$ при $`n>0`$ и $`(L_0-a)\lvert\psi\rangle=0`$, то же для $`\tilde L`$).

OPE: $`A(z)B(w)=\sum_kC_k(z-w)\,O_k(w)`$ — разложение по базису локальных операторов, сходящееся внутри корреляторов (радиально упорядоченных) при $`\lvert z-w\rvert`$, меньшем расстояния до остальных вставок. Первичное поле веса $`(h,\bar h)`$: $`T(z)O(w,\bar w)\sim\frac{hO}{(z-w)^2}+\frac{\partial O}{z-w}`$ и аналогично с $`\bar T`$ (эквивалентно: $`O\,dw^hd\bar w^{\bar h}`$ инвариантно при конформных заменах). Центральный заряд: $`T(z)T(w)\sim\frac{c/2}{(z-w)^4}+\frac{2T(w)}{(z-w)^2}+\frac{\partial T(w)}{z-w}`$, что равносильно соотношениям Вирасоро для $`L_n`$. ### Часть D

**D1.** Схема. Удобно $`[L_0,L_n]=-nL_n`$, $`[L_m,L_{-m}]=2mL_0`$; коцикл задан числами $`\omega(L_m,L_n)`$.
1. (а) Для $`\omega_V`$ все три слагаемых тождества коцикла на $`(L_k,L_m,L_n)`$ равны нулю, если $`k+m+n\neq0`$. При $`k+m+n=0`$, с $`c_j=j^3-j`$, $`c_{-j}=-c_j`$, тождество принимает вид $`(k-m)c_n+(m-n)c_k+(n-k)c_m=0`$. Линейная часть: $`(k-m)n+(m-n)k+(n-k)m=0`$ тождественно; кубическая:

<div align="center">

$`\displaystyle (k-m)n^3+(m-n)k^3+(n-k)m^3=(k-m)(k-n)(m-n)(k+m+n)=0.`$

</div>

Не кограница: для кограницы $`f([L_m,L_{-m}])=2mf(L_0)`$ линейно по $`m`$, а $`\omega_V(L_1,L_{-1})=0`$, $`\omega_V(L_2,L_{-2})=\frac12`$. Кограница от $`f(L_0)=\frac12`$, $`f(L_k)=0`$ ($`k\neq0`$): $`f([L_m,L_n])=(m-n)f(L_{m+n})=m\,\delta_{m+n,0}`$. Значит, $`m^3\delta_{m+n,0}=12\,\omega_V+m\,\delta_{m+n,0}`$ когомологичен $`12\,\omega_V`$.
2. (б) Положим $`f(L_n)=-\frac1n\omega(L_0,L_n)`$ при $`n\neq0`$, $`f(L_0)=0`$, $`\omega'=\omega-f([\cdot,\cdot])`$. Тогда $`\omega'(L_0,L_n)=\omega(L_0,L_n)+nf(L_n)=0`$ при $`n\neq0`$ (и при $`n=0`$ по кососимметричности). Тождество коцикла на $`(L_0,L_m,L_n)`$: $`\omega'(-mL_m,L_n)+\omega'((m-n)L_{m+n},L_0)+\omega'(nL_n,L_m)=-(m+n)\omega'(L_m,L_n)=0`$, откуда $`\omega'(L_m,L_n)=0`$ при $`m+n\neq0`$.
3. (в) Пусть $`c_m=\omega'(L_m,L_{-m})`$, $`c_{-m}=-c_m`$, $`c_0=0`$. Добавление кограницы от $`g`$ с $`g(L_0)=t`$, $`g(L_k)=0`$ ($`k\neq0`$) не портит (б) (так как $`[L_0,L_n]`$ не содержит $`L_0`$ при $`n\neq0`$) и сдвигает $`c_m`$ на $`-2mt`$; выберем $`t`$ так, чтобы $`c_1=0`$. Тождество коцикла на $`(L_1,L_m,L_{-m-1})`$ даёт $`(1-m)c_{m+1}+(2m+1)c_{-1}+(m+2)c_m=0`$, то есть $`(m-1)c_{m+1}=(m+2)c_m`$ при $`c_1=0`$. Отсюда $`c_m`$ при $`m\ge3`$ однозначно определяется $`c_2`$, и так как $`c_m=\frac{c_2}{6}(m^3-m)`$ удовлетворяет рекурсии ($`(m-1)(m+1)m(m+2)=(m+2)(m^3-m)`$), получаем $`c_m=2c_2\cdot\frac{m^3-m}{12}`$ при всех $`m`$ (для $`m<0`$ — по нечётности). Итак, $`\omega\sim\lambda\omega_V`$, $`\lambda=2c_2`$; единственность $`\lambda`$ — из (а) ($`\omega_V`$ не кограница). Значит, $`H^2(\mathcal{W};\mathbb{C})=\mathbb{C}[\omega_V]`$.
4. (г) Классы расширений ↔ $`H^2`$ (A2): нулевой класс — расщеплённое расширение $`\mathcal{W}\oplus\mathbb{C}`$; при $`\lambda\neq0`$ замена центрального элемента $`C\mapsto C/\lambda`$ даёт изоморфизм с алгеброй Вирасоро. Сдвиг $`L_0\mapsto L_0+tC`$ — смена сечения на $`f(L_0)=t`$, то есть добавление кограницы $`2mt\,\delta_{m+n,0}`$.

Критерии: (а) — 3 (коцикл — 2, не кограница и замечание про $`m^3`$ — 1); (б) — 3; (в) — 3 (рекурсия — 2, вывод — 1); (г) — 1. Для засчитывания КТ нужны полностью проверка коцикла в (а), (б) и (в).

**D2.** Схема.
1. ### Часть E

**E1.** (а) Пусть $`\mathcal{N}(f)=f''/f'=(\log f')'`$; тогда $`\lbrace f;w\rbrace=\mathcal{N}(f)'-\frac12\mathcal{N}(f)^2`$. <div align="center">
