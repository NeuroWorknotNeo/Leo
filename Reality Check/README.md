# Reality Check: диагностики по дисциплинам плана

Здесь лежат письменные экзамены ко всем дисциплинам из [plan.md](../plan.md). Каждый экзамен рассчитан на **120 минут** (исключение — расширенные экзамены по физике, см. [особые правила](#physics)) и отвечает на два вопроса: усвоена ли тема и на каком уровне. Галочку в плане стоит ставить по результату диагностики, а не по ощущению «книга прочитана».

## Устройство экзамена

Все диагностики устроены одинаково, поэтому результаты по разным дисциплинам можно сравнивать между собой.

| Часть | Что проверяет | Время | Баллы |
|---|---|---|---|
| A. Определения и формулировки | Знание языка: точные определения и теоремы со всеми условиями | ≈ 20 мин | 20 |
| B. Верно или неверно? | Понимание границ теорем: доказать или привести контрпример | ≈ 15 мин | 15 |
| C. Стандартные задачи | Рабочий навык: вычисления и типовые рассуждения | ≈ 35 мин | 30 |
| D. Ключевые доказательства | Владение центральными доказательствами, включая контрольную точку из plan.md | ≈ 30 мин | 20 |
| E. Повышенная сложность | Глубина: применение теории там, где путь не подсказан | ≈ 20 мин | 15 |

В конце каждого файла есть:
- **карта навыков**: какие задачи проверяют какую тему из «Содержания» карточки, чтобы было видно, что именно повторить;
- **таблица результатов и интерпретация** по пяти уровням;
- **ключ для самопроверки** со схемами решений и разбалловкой (свёрнут, открывать только после экзамена).

## Уровни

| Баллы | Уровень | Смысл |
|---|---|---|
| 0–39 | Не усвоено | Тему нужно проходить заново |
| 40–59 | Фрагментарно | Есть отдельные знания, но нет системы |
| 60–74 | Рабочий уровень | Можно двигаться дальше, но пробелы стоит закрыть |
| 75–89 | Уверенно | Можно ставить галочку в plan.md |
| 90–100 | Свободное владение | Тема усвоена на уровне, достаточном для продвинутых курсов |

**Правило галочки** (единое для всех дисциплин): итог не меньше 75 баллов, в каждой из частей A–D набрано не меньше половины, и все задачи с пометкой «контрольная точка» решены полностью. Обычно это задачи части D; если контрольная точка из plan.md состоит из нескольких пунктов, пометку несут несколько задач, и в файле это сказано явно. Часть E на галочку не влияет: она показывает запас прочности.

## Как пользоваться

1. **Честные условия.** Бумага, ручка, таймер. Никаких книг, конспектов, поиска и CAS. Если задача не решилась за отведённое время, это тоже результат.
2. **Строгая проверка.** Проверять себя по критериям из ключа. Если в доказательстве пропущен существенный шаг, балл снимается, даже если «идея была правильной».
3. **Перед началом дисциплины** полезно пройти части A и C диагностик её пререквизитов (поле «Требует» в шапке): так видно, нужно ли сначала что-то повторить.
4. **После окончания дисциплины** пройти диагностику целиком. Если галочка не получилась, по карте навыков выбрать темы для повторения и пересдать через 2–4 недели.
5. **Отложенная пересдача.** Через 6–12 месяцев после галочки стоит пересдать экзамен: устойчивое знание держится на уровне «уверенно» и без подготовки. Если результат упал ниже 60, тему стоит освежить до того, как на неё будут опираться следующие дисциплины.
6. **Не заучивать ключ.** Экзамен проверяет понимание, а не память на конкретные задачи. При пересдаче полезно брать аналогичные задачи из учебников, указанных в карточке дисциплины.

<a id="physics"></a>
## Особые правила для экзаменов по физике

Темы раздела «Физика для математиков» объёмные, и часть экзаменов по ним не сокращена до 120 минут. Такой экзамен называется **расширенным**: в его шапке указано время больше 120 минут, а в оглавлении раздела Mathematical Physics есть столбец «Время». Для расширенных экзаменов общие правила действуют со следующими изменениями.

1. **Время.** Отведённое время — из шапки экзамена, ориентир по частям — из заголовков частей. Таймер ставится на время из шапки, а не на 120 минут.
2. **Два захода.** Экзамен можно сдать за один раз или в два захода: первый — части A–C, второй — части D–E, каждый на сумму времени своих частей. Между заходами — не больше суток, без книг, конспектов и ключа. Во втором заходе к частям A–C не возвращаться. Способ сдачи записать в `notes.md`.
3. **Баллы и галочка — общие.** Шкала уровней и правило галочки те же, что для всех дисциплин: результаты по физике сравнимы с остальными.
4. **Физический уровень строгости.** Если в условии сказано «на физическом уровне строгости», аналитические оценки (сходимость, корректность интеграла по траекториям и т. п.) не требуются. Требуется всё, что перечислено в условии, и каждое утверждение должно быть сформулировано точно: что именно выводится и из каких предположений.
5. **Соглашения.** Знаки, нормировки и единицы — из абзаца «Соглашения» в начале экзамена. Ответ в другом общепринятом соглашении засчитывается, если оно названо явно и применено последовательно.

<a id="variants"></a>
## Как сдавать: выдача, попытки, варианты

Экзамены сдаются в паре с Claude по одной схеме.

```
Reality Check/
  <Область>/<Код>_<Название>.md   — основной экзамен (вариант v1) с ключом
  Variants/<Код>/v2.md, v3.md      — варианты для пересдач, тоже с ключом (см. Variants/README.md)
  Attempts/<Код>/<дата выдачи>/    — одна папка на одну попытку:
      exam.pdf                     — условия ровно той версии, которую решали (без ключа)
      notes.md                     — вариант и коммит, условия сдачи
      01.jpg, 02.jpg, … или solutions.pdf / solutions.md — решения
      REPORT.md                    — отчёт о проверке
  tools/exam_pdf.py                — сборка PDF с условиями
  exams_math_and_phys.zip          — PDF условий всех основных экзаменов одним архивом
```

1. **Выдача.** Написать Claude: «Хочу сдать A2». Claude соберёт `exam.pdf` из основного экзамена, создаст папку `Attempts/A2/<сегодняшняя дата>/` с `exam.pdf` и заготовкой `notes.md` и отправит её на GitHub. Дата в имени папки — дата выдачи; фактическая дата сдачи записывается в `notes.md`.
2. **Сдача.** Решать по `exam.pdf`, в честных условиях (см. выше; для физики — [особые правила](#physics)). Файл экзамена в репозитории до проверки не открывать: в нём ключ.
3. **Загрузка решений** в ту же папку и заполнение `notes.md` — как в [Attempts/README.md](Attempts/README.md).
4. **Проверка.** В новом диалоге: «Проверь мою попытку A2 от 2026-10-21». Проверка идёт по [протоколу](GRADING.md) и по той версии экзамена, что указана в `notes.md`. В папке появляется `REPORT.md`: баллы по каждой задаче, уровень, решение по галочке и что повторить. Результат записывается в журнал ниже, при выполнении критерия ставится галочка в `plan.md`.
5. **Пересдача.** Написать Claude: «Сделай вариант для пересдачи A2». Claude составит `Variants/A2/v2.md` по прошлым отчётам — с упором на слабые темы и с той же контрольной точкой, — проверит его и выдаст как в шаге 1. Правила составления — в [Variants/README.md](Variants/README.md).

**Только условия, без попытки.** PDF всех основных экзаменов лежат в архиве [`exams_math_and_phys.zip`](exams_math_and_phys.zip). Для зачётной попытки всё равно лучше шаг 1: тогда в папке попытки остаётся точная версия условий. Архив пересобирается после изменения экзаменов: `python3 "Reality Check/tools/exam_pdf.py" --zip "Reality Check/exams_math_and_phys.zip"`.
