
(б) Доказать, что всякий 2-коцикл $`\omega`$ когомологичен коциклу $`\omega'`$ с $`\omega'(L_0,L_n)=0`$ при всех $`n`$, и что для такого $`\omega'`$ имеем $`\omega'(L_m,L_n)=0`$ при $`m+n\neq0`$.

**D2.** Малые квантовые когомологии $`\mathbb{P}^n`$ и зеркальная модель Ландау–Гинзбурга. Пусть $`X=\mathbb{P}^n`$, $`n\ge1`$, $`H`$ — класс гиперплоскости, $`H^{\ast}(X;\mathbb{Q})=\mathbb{Q}[H]/(H^{n+1})`$, $`\int_XH^n=1`$; степень класса $`H^a`$ считается комплексной (равной $`a`$), $`(\alpha,\beta)=\int_X\alpha\cup\beta`$. Для $`d\ge0`$ положим $`\langle\gamma_1,\gamma_2,\gamma_3\rangle_d=\int_{\overline{M}_{0,3}(\mathbb{P}^n,d)}\mathrm{ev}_1^{\ast}\gamma_1\cup\mathrm{ev}_2^{\ast}\gamma_2\cup\mathrm{ev}_3^{\ast}\gamma_3`$, где $`\overline{M}_{0,3}(\mathbb{P}^n,d)`$ — пространство стабильных отображений рода $`0`$ степени $`d`$ с тремя отмеченными точками. Малое квантовое произведение на $`H^{\ast}(X;\mathbb{Q})\otimes\mathbb{Q}[q]`$ — $`\mathbb{Q}[q]`$-билинейное произведение, заданное формулой $`(\alpha\ast\beta,\gamma)=\sum_{d\ge0}q^d\langle\alpha,\beta,\gamma\rangle_d`$. Без доказательства можно использовать: $`\overline{M}_{0,3}(\mathbb{P}^n,d)`$ — гладкий собственный орбифолд ожидаемой размерности; если $`\Lambda_1,\Lambda_2,\Lambda_3`$ — линейные подпространства общего положения коразмерностей $`a,b,c`$ и размерность сходится, то $`\langle H^a,H^b,H^c\rangle_d`$ равно числу стабильных отображений $`(f;p_1,p_2,p_3)`$ степени $`d`$ с $`f(p_i)\in\Lambda_i`$, причём каждое считается с кратностью $`1`$.

(а) Найти $`\dim_{\mathbb{C}}\overline{M}_{0,3}(\mathbb{P}^n,d)`$ и доказать, что $`\langle H^a,H^b,H^c\rangle_d`$ ($`0\le a,b,c\le n`$) может быть ненулевым лишь при $`d\in\lbrace0,1\rbrace`$; найти соответствующие условия на $`a+b+c`$.

**E1.** (а) Для $`f=\frac{aw+b}{cw+e}`$, $`ae-bc=1`$: $`f'=(cw+e)^{-2}`$, $`\frac{f''}{f'}=-\frac{2c}{cw+e}`$, $`\frac{f'''}{f'}=\frac{6c^2}{(cw+e)^2}`$, поэтому $`\lbrace f;w\rbrace=\frac{6c^2-\frac32\cdot4c^2}{(cw+e)^2}=0`$. Для $`f=w+\varepsilon v`$: $`\lbrace f;w\rbrace=\frac{\varepsilon v'''}{1+\varepsilon v'}-\frac32\frac{\varepsilon^2v''^2}{(1+\varepsilon v')^2}=\varepsilon v'''+O(\varepsilon^2)`$. Связь: инфинитезимальная замена с полем $`v`$ меняет $`T`$ на $`\varepsilon\left(vT'+2v'T+\frac{c}{12}v'''\right)`$, и именно аномальный член $`\frac{c}{12}v'''`$ даёт центральный член; для $`L_m`$ поле пропорционально $`z^{m+1}`$, и $`v'''=(m+1)m(m-1)z^{m-2}`$, что после $`\oint\frac{dz}{2\pi i}`$ с полем $`z^{n+1}`$ даёт $`\frac{c}{12}(m^3-m)\delta_{m+n,0}`$. При $`m\in\lbrace-1,0,1\rbrace`$ поле — многочлен степени $`\le2`$, $`v'''=0`$: эти $`L_m`$ порождают $`\mathfrak{sl}_2`$ — алгебру дробно-линейных замен, для которых шварциан равен нулю и $`T`$ преобразуется как тензор веса $`2`$.
(б) $`f(w)=e^w`$: $`f'=f''=f'''=z`$, $`\lbrace f;w\rbrace=1-\frac32=-\frac12`$. Поэтому

<div align="center">

$`\displaystyle T_{\mathrm{cyl}}(w)=z^2T(z)-\frac{c}{24}=\sum_nL_ne^{-nw}-\frac{c}{24}.`$

</div>

Среднее $`e^{-n(\tau+i\sigma)}`$ по $`\sigma`$ равно $`\delta_{n0}`$, откуда $`\frac1{2\pi}\int_0^{2\pi}T_{\mathrm{cyl}}\,d\sigma=L_0-\frac{c}{24}`$; так же для $`\bar T`$, и $`H=L_0+\bar L_0-\frac{c}{12}`$.
(в) Замена $`w=\frac{2\pi}{\ell}w_\ell`$ линейна, её шварциан равен нулю, так что $`T_\ell(w_\ell)=\left(\frac{2\pi}{\ell}\right)^2T_{\mathrm{cyl}}(w)`$, и $`H_\ell=\frac{2\pi}{\ell}H`$. **E3.** (а) Общее решение $`\partial_+\partial_-X^m=0`$ с $`X^m(\tau,0)=y_i^m`$, $`X^m(\tau,\pi)=y_j^m`$:
