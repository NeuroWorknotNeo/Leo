# Reality Check Calibrating: попытки других людей

Сюда выкладываются решения экзаменов [Reality Check](../Reality%20Check/README.md), которые писали другие люди, и отчёты о проверке. Попытки нужны, чтобы откалибровать экзамены: понять, насколько трудны задачи, хватает ли времени и верны ли ключ и критерии. Результаты отсюда не влияют на журнал попыток, на галочки в [plan.md](../plan.md) и на составление вариантов для пересдач.

Здесь хранятся только решения и отчёты. Условия, ключи и критерии лежат в `Reality Check/`, сюда они не копируются.

## Структура

```
Reality Check Calibrating/<Код>/<вариант>/<участник>/
    01.jpg, … / solutions.pdf / solutions.md   — решения
    REPORT.md                                   — отчёт о проверке (создаёт Claude)
```

Например: `Reality Check Calibrating/A4/v2/ivan/`. Вместо имени можно взять псевдоним или инициалы.

## Как дать экзамен участнику

Отдать ему `exam.pdf` из своей папки попытки с этим вариантом. Например, для A4 v2 — `Reality Check/Attempts/A4/2026-10-23/exam.pdf`. Коммит, по которому собраны условия, указан в колонтитуле PDF. Условия сдачи для участника те же: время из шапки, один заход, без материалов, ключ не открывать.

## Как попросить проверку

Загрузить решения в папку участника и написать Claude, например:

> Проверь калибровочную попытку A4 v2 участника ivan: сдавал 2026-11-05, один заход, 175 минут, без материалов.

Условия сдачи (дата, время, материалы, что дописано после таймера) нужно сообщить в просьбе: отдельного `notes.md` здесь нет, Claude запишет их в шапку `REPORT.md`.

## Правила проверки (для Claude)

- Проверять по [`Reality Check/GRADING.md`](../Reality%20Check/GRADING.md) и по markdown-файлу варианта в `Reality Check/`: v1 — основной экзамен, vN — `Reality Check/Variants/<Код>/vN.md`. Версию брать по коммиту из колонтитула выданного PDF; если не ясно, какой PDF решался, спросить.
- `REPORT.md` положить в папку участника. В шапке указать участника, вариант, коммит и условия сдачи. Ссылки на экзамен — относительные, на файлы в `Reality Check/`.
- Ничего не менять в `Reality Check/`: не писать в журнал попыток, не ставить галочку в `plan.md`, не учитывать эти отчёты при составлении вариантов.
- Если калибровка выявила ошибку в условии или ключе, записать это в разделе «Замечания к экзамену» отчёта и сказать владельцу. Исправлять вариант — только с его согласия, отдельным коммитом, по правилу 6 из [`Variants/README.md`](../Reality%20Check/Variants/README.md).
- **Без спойлеров.** Если владелец сам ещё не сдавал этот вариант, отчёт содержит решения и ключ. Тогда в диалоге сообщать только баллы по частям, уровень и общие замечания о калибровке (трудность, время, неоднозначности без раскрытия решений), а владельцу напоминать, что `REPORT.md` и решения участника лучше не открывать до собственной проверки.
